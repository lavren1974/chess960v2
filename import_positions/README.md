# 🏁 Chess960 Engine Tournament: Agents Database Importer

---

> Проект по исследованию шахмат 960 (Fischer Random) через массовый турнир одинаковых движков Stockfish с разными начальными позициями.  
> Эта утилита предназначена для **одноразовой загрузки всех 1920 агентов** (960 за белых + 960 за чёрных) в базу данных Supabase.

---

## 🧠 Цель проекта

Провести масштабный круговой турнир:
- Каждая из 960 начальных позиций за белых (`sp_id = 1..960`) играет против каждой из 960 позиций за чёрных.
- Всего: **921 600 партий**.
- Все игры проводятся между **одинаковыми движками Stockfish**, чтобы изолировать влияние начальной расстановки фигур.

Ключевая идея:
> Каждая начальная позиция рассматривается как **отдельный стратегический агент**, обладающий уникальным поведением в зависимости от цвета и контекста.

---

## 🔢 Логика идентификации агентов (ID)

Чтобы упростить анализ, ссылки и работу в коде, принята следующая система ID:

| Цвет   | Формула ID       | Диапазон     |
|--------|------------------|-------------|
| Белые  | `id = sp_id + 1000` | 1001–1960   |
| Чёрные | `id = sp_id + 2000` | 2001–2960   |

### Пример:
- `sp_id = 1`, белые → `id = 1001`
- `sp_id = 1`, чёрные → `id = 2001`

✅ Преимущества:
- Предсказуемые ID без необходимости запроса к БД
- Удобные URL: `/sf_agents/1042`, `/positions/2150`
- Простой парсинг в Go: `color = if id < 2001 → 'w' else 'b'`

> ⚠️ Это не просто FEN-позиции — это **агенты**, каждый со своей статистикой, силой и ролью в турнире.

## 🗂 Структура таблицы `sf_agents`

```sql
CREATE TABLE public.sf_agents (
  id BIGINT PRIMARY KEY,
  sp_id INT NOT NULL CHECK (sp_id >= 0 AND sp_id < 960),
  mini_fen TEXT NOT NULL,
  color CHAR(1) NOT NULL CHECK (color IN ('w', 'b')),
  CONSTRAINT unique_sp_color UNIQUE (sp_id, color)
);
```

- `id`: уникальный ID агента (1001+ или 2001+)
- `sp_id`: официальный номер позиции Chess960 (1–960)
- `mini_fen`: строка типа `BBQNNRKR` — только расстановка фигур на первой линии
- `color`: `'w'` или `'b'` — определяет, за кого играет агент


## 📁 Источник данных

Файл: [`chess960original.csv`](chess960original.csv)  
Формат:

```csv
sp_id,white_mini_fen,black_mini_fen
1,BBQNNRKR,bbqnnrkr
2,BQNBNRKR,bqnbnrkr
...
960,RKRNNQBB,rkrnnqbb
```

> ✅ Данные соответствуют **официальной нумерации Fischer Random Chess (Chess960)**.

## 🛠 Утилита импорта: `import_positions.go`

Программа на Go, которая:
1. Читает CSV
2. Создаёт 1920 агентов (по одному на каждую комбинацию `sp_id + color`)
3. Отправляет их в Supabase **через REST API**, используя только:
   - `SUPABASE_URL`
   - `SUPABASE_KEY`

👉 Не требует прямого подключения к PostgreSQL.
